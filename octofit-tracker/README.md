OctoFit Tracker — multi-tier app scaffold

Ports:
- Frontend: 5173
- Backend: 8000
- MongoDB: 27017

This scaffold initializes a minimal React 19 + Vite frontend and a Node.js + Express + TypeScript backend with Mongoose.

Next steps:
1. Run `npm install` in each of `octofit-tracker/frontend` and `octofit-tracker/backend`.
2. Start MongoDB (listening on port 27017).
3. Run `npm run dev` in both frontend and backend to start development servers.
